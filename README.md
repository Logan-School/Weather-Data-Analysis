# Overview

In this program, the goal was to take a data set from the internet and determine the answers to questions based on the data. The data set included the weather for every day from the beginning of 2012 to the end of 2015 in both Seattle and New York. This program could allow me to find important information in the future without needing to sort through all the data by hand. some people for jobs around sorting and understanding data because it helps with making vital decisions, like which month to start selling sunscreen, or whether temperature trends will most likely help or hurt a certain sports event.

I got the data set from a github repository: https://github.com/observablehq/sample-datasets/blob/main/weather.csv?utm_source=chatgpt.com

[Software Demo Video] https://youtu.be/E1BJ7FsImQE

# Data Analysis Results

I answered 4 questions using my data analysis: how has the average temperature changed over each year in the time frame, what are the 5 hottest days in the time frame, what is the order of months from hottest on average to coolest on average, and which days have the widest temperature range or most precipitation. I found that the average temperature of the last year was 0.7 degrees celsius warmer than the first month, the highest temperature in the data set is 37.8 degrees celsius, July is the hottest month in the data set, there was a 20 degree celsius temperature range on one day, and there was 118.9 millimeters of precipitation on one day.
